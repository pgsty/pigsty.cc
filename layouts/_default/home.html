FEATURES · 核心特性

像专家一样自建 PostgreSQL

Pigsty 为您提供自建企业级 PostgreSQL 服务所需的一切，开源免费，自主可控

01 · HIGH AVAILABILITY

高可用标杆架构

故障自愈，高枕无忧

  • 基于 Patroni + Etcd 自动故障切换，HAProxy 流量自动均衡
  • 预置 pgBackRest PITR 时间点恢复，删库跑路也能找回数据
  • 内置 SSL/TLS 加密与访问控制模型，SELinux 防火墙全搞定

告别半夜故障值班 OnCall，硬件故障睡醒起来再修复

02 · INFRA AS CODE

基础设施即代码

言出法随，一键部署

  • 声明式配置，幂等性执行，Pigsty 式 IaC，无需操心细节
  • 海量可定制项，生产开发测试共享一套架构，仅配置不同
  • Ansible 幂等剧本，无需 K8s & Docker，裸机玩转云原生

一键复刻完整生产环境，单枪匹马管理海量集群

pigsty.yml 
# 定义一个 3 节点高可用集群
pg-test:
  hosts:
    10.10.10.11: { pg_role: primary }
    10.10.10.12: { pg_role: replica }
    10.10.10.13: { pg_role: replica }
  vars:
    pg_cluster: pg-test
    pg_version: 18
    pg_users:
      - { name: dbuser_app, password: DBUser.App }
    pg_databases:
      - { name: app, extensions: [ vector ]}

03 · OBSERVABILITY

可观测性技术栈

洞若观火，尽在掌握

  • 基于 Grafana + Victoria 的 SOTA 可观测性技术栈
  • 3000+ 监控指标，40+ 精调仪表盘，免配置开箱即用
  • 可独立部署使用，监控现有 RDS / PostgreSQL 实例

快速定位问题，数据驱动决策，告别空对空无效扯皮

04 · EXTENSIONS

数据库扩展生态

海纳百川，开箱即用

  • {{ .Site.Params.pgext_count }} 个 PostgreSQL 扩展，覆盖 16 个 Linux 系统，即装即用
  • 12 种 PG 内核：兼容 Oracle, SQL Server, MySQL, Mongo…
  • 功能模块：MinIO、Redis、Docker、Supabase 自建

灵活组合搭配，自由按需拼接，完全自主可控
